🔒 Group Title Lock

I-lock ang pangalan ng GC. Kapag may nagpalit, ibabalik sa tamang title sa loob ng ~120s. Chat command: !titlelock on <title> / !titlelock off / !titlelock status.

🖼️ Group Image Lock

I-lock ang larawan ng GC. Kapag may nagpalit, ibabalik sa tamang image URL sa loob ng ~120s. Chat command: !imagelock on <url> / !imagelock off.

🔒 Nickname Lock

I-lock ang nickname ng specific user. Kapag may nagpalit, ibabalik sa tamang nickname. Chat command: !nicklock on @user <nick> / !nicklock off @user / !nicklock list.

👥 Mass Set Nickname

Palitan ang nickname ng maraming member sa isang GC (max 50, may 1.5s pagitan kada user). Chat command: !massnn <nick> @user1 @user2.

Mga admin

    
Mga Facebook ID na puwedeng gumamit ng admin commands (!gcname, !troll, !eco, !titlelock, !nicklock, !massnn, !spam, !imagelock) sa chat. Laging admin ang mismong bot account. Isang ID kada linya, o paghiwalayin ng comma.

    
Para sa owner commands (!setbal, !additem), mag-set ng OWNER_IDS sa Railway Variables.
